# EIRENƎ JEWELS • Contemporary Demi-Fine Atelier

> **Sculpted stillness for the daily ritual.**  
> An ultra-luxury, anti-slop digital maison engineered for [**EIRENƎ JEWELS**](https://www.instagram.com/eirenejewels_/). Built with Next.js 15, React 19, TypeScript, Tailwind CSS v4, and Zustand.

---

## 🏛️ Brand Provenance & Aesthetic Identity

* **Etymology:** Rooted in the ancient Greek ideal of *Eirēnē* (Εἰρήνη)—serene stillness, composure, and quiet sovereignty.
* **Metallurgical Standard:** 18-karat micro-vermeil immersion (2.5µm PVD) over 316L surgical marine-grade stainless steel cores. 100% waterproof, sweatproof, perfume-resistant, and hypoallergenic.
* **Atelier Provenance:** Inspected and dispatched piece-by-piece from Ambala, India with insured Pan-India transit.
* **Social Line:** Direct reservation bridge connecting seamlessly to [`@eirenejewels_`](https://www.instagram.com/eirenejewels_/) on Instagram and WhatsApp concierge.

## 💎 World-Class Anti-Slop Design Principles

Curated in accordance with high-fashion house aesthetics and calibrated against award-winning gallery sites (Awwwards, One Page Love):

* **Zero AI Tells:**
  * ❌ No generic rounded SaaS cards with soft drop shadows.
  * ❌ No violet or neon cyberpunk gradients.
  * ❌ No generic 01/02/03 badges or 3-column clip-art icon grids.
  * ❌ No stock testimonials with fake customer avatars.
* **Architectural Palette:**
  * **Ground:** Alabaster Parchment (`#FAF8F5`) and Travertine Stone (`#EAE3D9`).
  * **Ink:** Obsidian Espresso (`#121110`) and Velvety Charcoal (`#2A2624`).
  * **Accent:** Muted Champagne Bronze (`#C4A47C` / `#9E7D4E`).
* **Typography Hierarchy:**
  * *Italiana* & *Cormorant Garamond* (sculptural high-contrast serif display).
  * *Plus Jakarta Sans* (restrained geometric sans for specifications and dimensions).
  * *Cinzel* (Roman hallmark capitals for atelier authentication).

├── app/
│   ├── globals.css         # Custom luxury theme tokens & typography

│   └── sitemap.ts          # Automated XML sitemap generation

│   ├── Header.tsx          # Sticky luxury nav with currency & bag triggers
│   ├── Hero.tsx            # Asymmetrical editorial gallery opening

│   ├── Manifesto.tsx       # Metallurgy, 316L core & anti-tarnish guarantee
│   ├── ProductDrawer.tsx   # Detailed metallurgical spec & Instagram link
│   ├── CartDrawer.tsx      # Slide-out bag with free shipping meter & gift box
│   ├── ConciergeModal.tsx  # WhatsApp & Instagram DM reservation desk
│   └── Footer.tsx          # Atelier provenance, care ritual & legal hallmarks

│   └── products.ts         # Verified products extracted from @eirenejewels_

## 🚀 Getting Started

### 1. Prerequisites
* Node.js 20+ (Node 22 LTS recommended)
* npm 10+

### 2. Installation
```bash
npm install
```

### 3. Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the atelier in your browser.

### 4. Production Build & Verification
```bash
npm run build
npm run start
```

## 📦 Deployment to Vercel

This repository is pre-configured for zero-configuration, instant deployment on Vercel:

1. Import the repository into your Vercel Dashboard: `https://github.com/TattvaAI/jewels`
2. Framework Preset: **Next.js**
3. Build Command: `npm run build`
4. Output Directory: `.next`
5. Click **Deploy**.
